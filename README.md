# Perceptrons

An independent visual companion to the Code Institute Section 8 sequence on perceptrons:

- letter classification with one neuron;
- implementation of a one-neuron classifier in spreadsheets; and
- the move from one neuron to a multilayer network.

The guide uses original, simplified T, Z and E examples to make the path from picture → measured inputs → score → prediction → learning → larger network visible. It is a teaching companion, not official Code Institute material. Course links and independent enrichment sources are listed in the guide's Sources section.

## Open the guide

Open [`index.html`](index.html) in a browser, or visit the published GitHub Pages version:

<https://tidyweb.github.io/Perceptrons/>

The `assets/` folder contains the local TidyWeb logo required by the page.
