From pictures to a decision

How can one neuron recognise a letter?

A computer cannot look at a letter the way you do. It receives numbers that describe the picture. A perceptron uses those numbers to make a decision, then adjusts its settings when it gets an example wrong.

01Read the pictures

What earns a 1?

We want a simple yes-or-no answer: “Is this a capital T?” Choosing between T and not T is classification. You have met a two-state answer in Python: True or False is a Boolean. Here, the known answer is 1 for T and 0 for not T.

Before a perceptron can use a picture, we must turn it into numbers. Each number answers one exact question about a visible part of the letter. The orange stroke below shows the part that counts; the tick or cross and the number state the result. Here is how one such number can come from pixels.

How does a picture become numbers?

Think back to the 28-by-28 images in Images ML. Each picture has 28 rows and 28 columns of pixels: 784 fixed positions. A pixel has a place (row and column) and a value (how light or dark that place is). The value is not the location.

Read the small grid

This is a simplified 7-by-7 drawing. White square = no ink (0); black or orange square = ink (1). Orange marks the five positions our top-bar question checks: row 0, columns 1 to 5. For example, row 0 column 1 has ink (1); row 0 column 0 is blank (0).

Apply a measuring rule

If all five watched positions contain ink, record x₁ = 1. Both T and Z pass. This one output number summarises several pixel values; it is not a pixel location.

Where the perceptron starts: in this guide, the measuring rule makes x₁ and x₂ first; the perceptron receives those two results. A perceptron could instead receive all 784 pixel values directly, giving each pixel value its own weight. It would not first name a top bar on its own. The exact five-square check is a teaching simplification; real handwriting needs more tolerant measurement.

The letter x means an input number. The small 1 and 2 tell us which question produced it. Neither x₁ nor x₂ is a single pixel; each is a yes-or-no result made by checking part of the picture.

03Feature questions

What if the question is too loose?

What if, instead of asking for a vertical stroke centred beneath the top bar, we ask merely for a long vertical stroke? This sounds close, but it changes what the perceptron receives.

Loose x₂ · Is there a long vertical stroke?

Orange shows the stroke that now qualifies. Both T and E pass this looser question.

What changed: the E has not changed. The question changed. Its left-hand stroke now earns a 1 because the question no longer says the stroke must be centred.

With the loose question

Picture T and Picture E both become (1, 1). The perceptron receives identical inputs for both.

T → (1, 1)
E → (1, 1)
Same input → same answer, so one must be wrong.

With the precise question

T keeps (1, 1). E becomes (1, 0), because its vertical is on the left.

T → (1, 1) → T ✓
E → (1, 0) → not T ✓

The important point: if T and E are both reduced to the same two numbers, one perceptron must give them the same answer. The feature question decides which picture details reach it. Once “central” has been left out, adjusting its settings cannot recover that lost position. With the precise question, the two pictures have different inputs, so the perceptron can learn to give different answers.

04Training

How does it learn?

The precise questions tell the perceptron what each picture contains. Training teaches it what to do with those two answers. We show it pictures whose correct labels we already know, compare each prediction with that label, and adjust its settings after a mistake.

First, what training does

Suppose the perceptron first says “not T” for Picture T. The known answer is T, so that is a mistake. The next picture checks whether the correction also works for E. The small loop below is the job of training.

1 · Picture

Picture T has a top bar and a centred vertical: 1, 1.

2 · Known answer

We already know its label: 1 · T.

3 · Prediction

The current settings say 0 · not T. That is wrong.

4 · Correction

Change the settings, then try the picture again.

These examples are the training set. After training, use unseen pictures to check whether the rule works beyond the examples it practised on. The input questions themselves stay the same throughout this run.

Human bridge: practice strengthens a pathway. When you practise guitar, your left hand and right hand learn a coordinated pattern: different fingers find different strings, and repeated practice makes that pathway easier to use. In a biological nervous system, repeated activity can strengthen connections between neurons. A machine-learning weight is the machine’s numerical way of representing how strongly one input should influence the next calculation. This is a useful bridge, not a claim that one number reproduces a biological synapse.

What is a weight?

Each input has an adjustable number that controls how much its answer adds to the score. That number is a weight. The top bar and the centred stroke still give the same answers for Picture T: 1 and 1. In the two cards, only the number attached to the centred stroke changes.

For Picture E, the precise central-stroke answer is 0, so this stroke weight contributes 0 to E even when its weight is 2.

We call the top-bar weight w₁ and the centred-stroke weight w₂. The contributions are x₁ × w₁ and x₂ × w₂. Here x₁ and x₂ are the measured answers, while the weights are adjustable settings. A weight is not a stroke or a pixel.

What is bias?

The two contributions make a total, but the perceptron still needs a point at which it will say “T”. Imagine that point as a movable cutoff on a score line. In both cards below, Picture T's total stays at 2. Only the cutoff moves.

The marked positions and numbers show the comparison; colour is an extra cue. Moving this cutoff affects every picture, not just T.

Human bridge: bias gives the rule some room. A machine begins with literal numerical rules: an input contributes a value, and the total is compared with a cutoff. The bias is an adjustable offset that moves that cutoff. It gives the decision rule a little wiggle room instead of forcing the boundary to stay fixed at the origin. That can help the model place its boundary around the examples it is learning. Bias is not an outlier detector by itself; it shifts the baseline for every input.

The adjustable setting that moves the cutoff is called the bias, written b. We add it to the total and say “T” when the result reaches zero. A cutoff of 1.5 is written as bias −1.5, because 2 − 1.5 = 0.5. A cutoff of 2.5 is bias −2.5, because 2 − 2.5 = −0.5. That result is the score, not a probability.

The whole decision: score = x₁ × w₁ + x₂ × w₂ + b. Score at or above 0 → T; below 0 → not T. Turning the score into this yes-or-no answer is a step activation. We have now seen every part of the formula in a picture.

Watch the settings learn from T and E

Keep the precise feature questions. Start a fresh training run with top-bar weight 1, centred-stroke weight 1, and a cutoff of 2.5. In symbols these settings are w₁ = 1, w₂ = 1, b = −2.5. These are chosen starting values, not facts about the letters.

1 · Picture T exposes a mistake w₁=1 · w₂=1 · b=−2.5

Its inputs are (1, 1). Known answer: 1 · T. Current score: 1×1 + 1×1 − 2.5 = −0.5, so prediction: 0 · not T.

The current bias is too negative: it places the cutoff at 2.5, so the real T misses the boundary. Prediction 0 versus known answer 1: revise the settings.

2 · Correct for Picture T new: w₁=2 · w₂=2 · b=−1.5

With a correction size of 1, add 1 to each weight whose input was 1 and add 1 to the bias.

w₁: 1 → 2   w₂: 1 → 2   b: −2.5 → −1.5

Try T again with the revised bias: 1×2 + 1×2 − 1.5 = 2.5 → 1 · T.

The revised bias moves the cutoff down. T now crosses it, but this change also affects other pictures.

3 · Picture E reveals the next mistake current: w₁=2 · w₂=2 · b=−1.5

E's inputs are (1, 0). Known answer: 0 · not T. With the current settings, 1×2 + 0×2 − 1.5 = 0.5 → prediction 1 · T.

The current bias is now too generous: it leaves E's score above zero, so E escapes rejection. Prediction 1 versus known answer 0: revise the settings.

4 · Correct for Picture E, then recheck T new: w₁=1 · w₂=2 · b=−2.5

Subtract 1 from the top-bar weight, whose input was 1, and from the bias. E's centred-stroke input was 0, so that weight stays at 2.

w₁: 2 → 1   w₂: 2 → 2   b: −1.5 → −2.5

Use the revised bias for both checks: E: 1×1 + 0×2 − 2.5 = −1.5 → not T. T: 1×1 + 1×2 − 2.5 = 0.5 → T.

The revised bias rejects E while T remains above zero. Both pictures now receive their known labels.

One correction can change the answer for another picture, so training goes through the examples again as needed. A complete pass through the training examples is an epoch. The calculation above is the perceptron update with correction size 1: new weight = old weight + (known label − prediction) × input; the bias gets the same correction without an input multiplier. A different correction size would scale each change.

The feature definitions stayed precise throughout. Training changed weights and bias; it did not redraw the letters or redefine what earns a 1. Now we can put this final rule into spreadsheet cells.

05Spreadsheet

See the precise rule in cells

A spreadsheet can show the same two-feature decision without hiding any steps. One row is one picture. The weights and bias live in fixed cells. This illustrative layout uses Picture T, Picture E, and the settings reached at the end of section four.

First, learn how to read the cell references

This is a teaching key, not a full screenshot of the worksheet. The letters A to F name columns. A formula adds a row number so it can point to one exact cell. In this example, row 2 is Picture T and row 3 is Picture E.

Read across a picture row: A holds x₁, the top-bar answer; B holds x₂, the centred-stroke answer; C holds the known label; D holds the score; E holds the prediction; and F checks the error. So A2 means “Picture T's value in column A” (1), while B2 means “Picture T's value in column B” (1). For Picture E, A3 is 1 and B3 is 0. The letter tells you the column; the number tells you the picture row.

The settings sit in separate cells: J2 stores w₁ = 1, J3 stores w₂ = 2, and J4 stores b = −2.5. The dollar signs in $J$2, $J$3, and $J$4 tell the spreadsheet to keep using those same settings when a formula is copied to another row.

Now read the score in D2: =A2*$J$2+B2*$J$3+$J$4 means “Picture T's top-bar answer × its weight, plus Picture T's centred-stroke answer × its weight, plus the bias”: 1×1 + 1×2 − 2.5 = 0.5. D3 repeats the same recipe for Picture E: 1×1 + 0×2 − 2.5 = −1.5.

Then E turns the score into the prediction. =IF(D2>=0,1,0) means “look at Picture T's score in D2; if it is at least zero, predict 1; otherwise predict 0.” So D is the score, E reads that same-row score, and F compares the prediction with C, the known answer.

06Limits

What can one neuron separate?

A single perceptron can separate cases when one straight dividing line can put every YES case on one side and every NO case on the other. Our simple T rule fits that shape. To see where the rule reaches its limit, leave the letters aside for a moment and use two tiny yes-or-no inputs.

Imagine two switches. Each switch can be 0 (off) or 1 (on). We want the light on when exactly one switch is on. If both switches are off, the light is off; if both are on, the light is also off.

OR · at least one

YES when one or both inputs are on. The both-on case counts as YES.

0, 0 → NO
0, 1 → YES
1, 0 → YES
1, 1 → YES

XOR · exactly one

YES when one input is on and the other is off. Exclusive means the both-on case is excluded.

0, 0 → NO
0, 1 → YES
1, 0 → YES
1, 1 → NO

This is the definition of exclusive OR, shortened to XOR. For this example, the two numbers are abstract inputs; they are not the top-bar and centred-stroke questions from the letter example.

XOR · the two YES cases sit at opposite corners

Read each square as one complete input pair. The words state the answer; the shading is only an extra cue.

0, 0NO · neither
1, 0YES · one on
0, 1YES · one on
1, 1NO · both on

The YES cases are diagonally opposite; they are not next to each other.

Cases that one straight boundary can separate are called linearly separable. XOR is not linearly separable: its two YES cases are opposite corners, so any straight line that keeps one NO case out also cuts off one of the YES cases. More training cannot change that geometry. The next section shows how several neurons can divide the smaller questions between them and then combine their answers.

07More neurons

Why add layers?

XOR needs two separate YES regions, but one neuron can draw only one straight boundary. A network helps by giving different neurons smaller jobs: each intermediate neuron notices a simpler pattern, and a later neuron combines those intermediate results.

Think of two spotters watching the switches. One spotter asks, “Is the first switch on and the second off?” The other asks, “Is the second switch on and the first off?” Each spotter adds its weighted inputs and bias, then an activation turns that score into the detector's output. A final decision says YES if either spotter reports a match. These intermediate results are called a hidden layer because they help produce the answer but are not the final answer shown to us.

Teaching schematic: this shows the jobs a small network can divide between neurons, not the exact weights a trained model must learn.

Why does this help? Each hidden neuron can create its own boundary, and the output neuron can combine the hidden results. The overall decision can therefore be built from more than one simple region. A nonlinear activation between layers is the crucial step that lets those boundaries combine into a more complicated shape. If every layer only repeats multiplication and addition, the layers collapse mathematically into another linear calculation, and XOR still defeats them.

How does the larger network learn? It still follows the same basic loop: predict, compare the prediction with the known answer, measure the error, adjust the settings, and try again. In a multilayer network, backpropagation sends information about the final error backwards: the output layer receives an adjustment signal, then earlier layers receive the part of the signal linked to their contribution. Software uses those signals to update weights and biases.

1 · Predict

Inputs pass through the hidden detectors and output.

2 · Compare

The known label reveals whether the answer was wrong.

3 · Trace

Backpropagation sends responsibility backwards through the layers.

4 · Adjust

Weights and biases change before the next example.

From “T or not T?” to many letters

Our one output gives one yes/no answer. When the task has many possible classes, the output layer can provide one score per class: ten scores for the digits 0 to 9, or 26 scores for uppercase letters. The strongest score supplies the chosen class. A technique called softmax can turn those scores into comparable values that add up to 1. Real letter images usually provide many pixel values rather than just our two hand-picked features, but the route stays recognisable: inputs → intermediate detectors → output scores.

More neurons do not automatically mean better results. The examples must represent the kinds of writing the model will see later, and its decisions must be checked on unseen pictures.

08Check yourself

Can you follow the pictures?

Use the reference pictures at the top. Try each question before opening its answer.

  1. Which part of Pictures T, Z, and E earns a 1 for x₁?
    Show the answer

    Each has a top horizontal bar. All three receive x₁ = 1; that bar is highlighted orange in the first feature board.

  2. Why does Picture E receive x₂ = 0 under the precise definition?
    Show the answer

    Its long vertical stroke is on the left, not centred beneath the top bar. The stroke exists, but it does not match this specific question.

  3. What changes when x₂ asks only for a long vertical stroke?
    Show the answer

    Picture E's left stroke now qualifies. T and E both become (1, 1). Since the perceptron receives identical inputs, it must give them the same answer; one of those labels will be wrong.

  4. Picture T stays (1, 1). What happens when only its centred-stroke weight changes from 1 to 2?
    Show the answer

    Its contribution from that input grows from 1 to 2. With the top-bar weight still 1, the total before the cutoff grows from 2 to 3. The picture and input values have not changed.

  5. Picture T's total is 2. What happens when the cutoff moves from 1.5 to 2.5?
    Show the answer

    At 1.5, T reaches the cutoff. At 2.5, it falls short. In the score formula the two cutoffs correspond to biases of −1.5 and −2.5.

  6. After both T and E corrections, what score does Picture E get?
    Show the answer

    The final settings are w₁ = 1, w₂ = 2, and b = −2.5. E has (1, 0), so its score is 1×1 + 0×2 − 2.5 = −1.5. It is classified as not T.

  7. Why does a multilayer network need nonlinear activations for a pattern such as XOR?
    Show the answer

    Stacked weighted sums are still linear overall. Nonlinear activations let the network form more complex dividing boundaries.
